# Sidebar

The sidebar mirrors the structure: one project, its desks, and the things the project owns.

- Order, top to bottom: project switcher, Search everything (⌘K / Ctrl+K), Desks, Notes, Conversations, Library; at the foot, All projects and Global library.
- The open desk is an `ink` row with `paper` text and a small `highlight` dot. On Windows it is a light row with a 3px `ink` bar on its left instead.
- Notes lists pinned notes, All notes with a count, then your tags as outlined pills.
- Conversations shows the project thread first, with an unread count in `pencil`, then side threads.
- Library rows are by type with counts. Linked types (videos, web pages) carry a link icon or the word "linked".

The consumer provides the project, its desks, pinned notes, tags, threads and library counts.
