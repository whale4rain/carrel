# Composer

The composer is where you point and ask in one motion; it floats on the mat at the bottom of the desk.

- Paper lifted: `paper`, `radius-control`, `shadow-lift`. Centered, at most 640px wide.
- Captured *that.* chips stack above the input, led by "pointing at" in italic `ink-muted`. Each chip can be removed.
- Empty, the composer is one line: "Ask about that…". It grows only when chips or text are added.
- Send is the only filled control, `ink` on `paper`. The agent's reply appears as marginalia near what it points at, not in a chat log.

The consumer provides the captured chips, the input value and the send handler.
