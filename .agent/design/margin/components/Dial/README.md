# Dial

The dial sets who does the work in a module: the agent (output) or you (growth).

- Five steps from Output to Growth. Track and thumb in `ink`; the current end's label in `ink`, the other in `ink-muted`.
- A one-line hint under it says what the agent will do at this step, in plain words.
- Only you move the dial. The agent may suggest a change in its marginalia; it never moves it.
- Set per module and shown in the module header. On the phone it lives in the module's settings sheet.

The consumer provides the module, the current step and the change handler.
