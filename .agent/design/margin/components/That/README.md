# That

*that.* is the pointing mark: a highlighter band in the source and a chip wherever it is used.

- Chip: `highlight` fill, `highlight-ink` text, `position` style, `radius-mark`. It shows a position, never a sentence.
- In the source: `highlight-soft` under the words, `ink` text.
- States: default; active (a 3px `highlight-soft` halo, and the source band brightens at the same time); proposed by the agent (`pencil-wash`, dashed `pencil`); asked for in growth mode (dashed `graphite`, "that. ?"); snapshot when the source changed (`paper-2`, `ink-muted`, "saved").
- Yellow is reserved for *that.* Never use `highlight` for warnings, selection or emphasis.
- Capture with one key (⌘ .) on a selection, a video moment or a region. Drag a chip into a note or the composer.

The consumer provides the anchor (where it points) and the saved snapshot.
