# Carrel

A desk for long-running study and research, built on
[tnega](https://github.com/whale4rain/tnega). Lay out books, videos, web pages
and notes on a free-layout desk, point at exact passages with *that.*, and keep
the agent one shortcut away.

Early development. Start with [AGENTS.md](AGENTS.md).

## Try it

Needs Node 22.19 or later and pnpm 10 (`corepack enable` sets it up).

```bash
pnpm install
pnpm check   # lint, typecheck, tests
pnpm dev     # opens the desktop app
```
